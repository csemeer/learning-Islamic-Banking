# Islamic Banking Learning App

A comprehensive, professional learning platform for mastering Islamic Banking concepts from foundations to advanced topics.

## Features

### 📚 **4-Tier Progressive Learning System**

1. **Foundation Level** - Core Islamic banking principles
2. **Products Level** - CASA and deposit products
3. **Financing Level** - Islamic financing mechanisms
4. **Advanced Level** - Sukuk, Takaful, and governance

### 🎯 **Learning Tools**

- **Interactive Modules** - 60+ topics with detailed explanations
- **Flashcards** - Memorize key terms with Arabic translations
- **Quizzes** - Test your knowledge with instant feedback
- **Glossary** - Searchable dictionary of Islamic banking terms
- **Comparison Tables** - Islamic vs Conventional banking side-by-side
- **Progress Tracking** - Monitor your learning journey

### 💡 **Key Topics Covered**

#### Foundations
- Riba (Interest)
- Gharar (Uncertainty)
- Maysir (Gambling)
- Halal & Haram investments

#### CASA Products
- Wadiah (Safekeeping)
- Mudharabah (Profit-sharing)
- Qard Hassan (Benevolent loan)

#### Financing Products
- Murabahah (Cost-plus sale)
- Ijarah (Leasing)
- Musharakah (Partnership)
- Diminishing Musharakah
- Istisna (Manufacturing)
- Salam (Forward purchase)

#### Advanced Concepts
- Sukuk (Islamic bonds)
- Takaful (Islamic insurance)
- Wakalah (Agency)
- Shariah Governance
- Risk Management

## Technology Stack

- **React 18** - Modern UI library

- **Tailwind CSS** - Utility-first styling
- **Lucide React** - Beautiful icons

## Getting Started

### Prerequisites

- Node.js 16+ and npm

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
